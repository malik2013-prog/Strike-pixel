# Strike Pixel API — ПРОСТАЯ ВЕРСИЯ

НИКАКИХ НАСТРОЕК! Токен уже встроен в код.

## 🚀 Деплой (1 минута)

1. Иди на [vercel.com](https://vercel.com)
2. Sign Up (через GitHub)
3. Нажми **Add New... → Project**
4. Выбери **Upload** → перетащи папку `vercel-api-simple`
5. Нажми **Deploy**
6. Готово! Получишь URL типа `https://strike-pixel-abc.vercel.app`

Никаких Environment Variables, никаких настроек — просто загрузил и работает!

## 🔗 URL для сайта

После деплоя твой API будет по адресу:
```
https://ТВОЙ-ПРОЕКТ.vercel.app/api/send
```

Вставь этот URL в `index.html` сайта в строку:
```javascript
const VERCEL_API_URL='https://ТВОЙ-ПРОЕКТ.vercel.app/api/send';
```
